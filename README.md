# Email Spam Detection

## Project Overview
Classifies messages as **Spam** or **Ham** using NLP and machine learning.

## Objective
Build a model to automatically detect spam messages.

## Dataset
The dataset contains message text and labels: **Ham** and **Spam**.

## Technologies Used
Python, Pandas, Matplotlib, Seaborn, Scikit-learn, NLP.

## Workflow
1. Load and clean data
2. Perform EDA
3. Apply TF-IDF
4. Train Naive Bayes and Logistic Regression
5. Evaluate and compare models

## Evaluation
Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

## Conclusion
The project demonstrates NLP-based text classification for spam detection.

# Car Price Prediction

## Project Overview
Predicts used-car selling prices using machine learning.

## Objective
Estimate car prices using vehicle features such as age, mileage, fuel type, transmission, and engine size.

## Dataset
The dataset contains **502 used-car records** with vehicle and price information.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Joblib.

## Workflow
1. Load and clean data
2. Handle missing values
3. Perform feature engineering
4. Conduct EDA
5. Preprocess features
6. Train regression models
7. Evaluate and select the best model

## Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation
MAE, MSE, RMSE, and R² Score.

## Conclusion
The project demonstrates a complete machine learning regression workflow for car price prediction.

# Iris Flower Classification

## Project Overview
Classifies iris flowers into **Setosa, Versicolor, and Virginica** using machine learning.

## Objective
Predict iris species using sepal and petal measurements.

## Dataset
The Iris dataset contains **150 samples and 4 features**:
Sepal Length, Sepal Width, Petal Length, and Petal Width.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Workflow
1. Load the dataset
2. Perform EDA
3. Visualize features
4. Split the data
5. Train classification models
6. Evaluate and compare models

## Models
- Logistic Regression
- K-Nearest Neighbors

## Evaluation
Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

## Conclusion
The project demonstrates EDA, visualization, and supervised machine learning for iris flower classification.
